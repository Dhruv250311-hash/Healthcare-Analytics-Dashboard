# HealthCare Analytics Dashboard 

An interactive Power BI dashboard developed to analyze patient records, hospital performance, treatment costs, insurance coverage, and healthcare operations through interactive visualizations and business intelligence.

# Purpose

The primary objective of this dashboard is to transform raw healthcare data into meaningful insights that help hospitals and healthcare organizations monitor patient trends, improve operational efficiency, evaluate financial performance, and support data-driven decision-making.

# Business Problem Statement

Healthcare organizations generate thousands of patient records every day. Without proper reporting and visualization, it becomes difficult to monitor patient admissions, identify common medical conditions, evaluate treatment costs, track insurance coverage, and analyze hospital performance.

This dashboard addresses these challenges by converting healthcare data into interactive reports that simplify analysis and support informed healthcare decisions.

# Introduction

Healthcare data contains valuable information about patients, treatments, hospital operations, and financial performance. However, raw datasets alone cannot provide meaningful insights without proper analysis.

This HealthCare Analytics Dashboard is developed using Microsoft Power BI,Power Query Editor, SQL etc. to visualize patient demographics, billing information, insurance providers, medical conditions, admissions, and healthcare trends. The dashboard enables users to monitor hospital performance, understand patient distribution, and identify opportunities for operational improvement.

# Business Questions

The dashboard helps answer the following questions:

- How many patients were admitted?
- What is the total billing amount?
- Which medical conditions are most common?
- What is the revenue model of this healthcare organization ?
- Which insurance provider covers the highest number of patients?
- Which hospitals have the highest admissions?
- What is the patient distribution by gender and age?
